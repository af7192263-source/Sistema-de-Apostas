# 💰 Sistema de Apostas Online

Sistema profissional de análise e gestão de apostas esportivas.

## ✅ PRONTO PARA COLOCAR ONLINE!

Este projeto está configurado para rodar na **Vercel** (plataforma grátis).

## 📁 Arquivos:

- `index.html` - Frontend (interface do usuário)
- `api.js` - Backend (API de dados)
- `package.json` - Dependências
- `vercel.json` - Configuração Vercel

## 🚀 Como fazer Deploy na Vercel:

### **1. Crie conta no GitHub**
- Acesse: https://github.com
- "Sign Up" e confirme email

### **2. Crie um repositório**
- Clique "New"
- Nome: `sistema-apostas`
- Clique "Create repository"

### **3. Suba os arquivos**
- Clique "uploading an existing file"
- Arraste todos os 5 arquivos:
  - `index.html`
  - `api.js`
  - `package.json`
  - `vercel.json`
  - `.gitignore`
- Clique "Commit changes"

### **4. Conecte à Vercel**
- Acesse: https://vercel.com
- "Sign Up" com GitHub
- Clique "New Project"
- Selecione `sistema-apostas`
- Clique "Import"
- Clique "Deploy"

### **5. Pronto! 🎉**
- Você recebe um link tipo: `https://seu-projeto.vercel.app`
- Sistema está ONLINE e funcional!

## 🧪 Testar Localmente (opcional):
